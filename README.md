# درب 0.8.2

[تنزيل APK](apk/Darb-v0.8.2.apk) — أندرويد 8 فأحدث.

قائمة تطبيقات مستوحاة من الآيفون بهوية درب: حواف مستديرة وإضاءة وظلال خفيفة تعطي عمقًا بصريًا، أسماء واضحة، ومعاينة حتى 9 تطبيقات ظاهرة داخل المجلد. دقة الأيقونات 128×128. أدوات القائمة تحت «تنظيم التطبيقات». يحافظ على المجلدات والمفضّلات والترتيب، وعلى صفحة الوسائط المبسطة في 0.8.1.

ثبّت فوق النسخة الحالية دون حذفها. إذا رفض مُحدّث درب فحص التوقيع، افتح APK من مدير ملفات أندرويد؛ مشكلة الفحص على الشاشة المتأثرة لم تُحسم بعد.

اجتاز البناء وفحص التوقيع واختبارات الواجهة غير البصرية. لم يتم اختباره بصريًا أو تثبيته على شاشة فعلية في بيئة التطوير.
