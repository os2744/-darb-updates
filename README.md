# درب 0.9.0

[تنزيل APK](apk/Darb-v0.9.0.apk) — أندرويد 8 فأحدث.

- تخصيص البطاقات بمعاينة تفاعلية، سحب للترتيب، ثلاثة أحجام وأزرار نقل بديلة، مع التراجع عن تعديلات الجلسة. الحفظ مباشر.
- إعدادات الوسائط بنفس مجموعات وصفوف الإعدادات العامة، داخل الزر الجانبي.
- حتى 20 ثيمًا خاصًا: ألوان الخلفية والبطاقات والنص والتمييز، معاينة قبل الحفظ، تسمية وتعديل وحذف. تبقى الثيمات الستة المقترحة. تطبيق ثيم خاص يوقف الجدولة.

يحتفظ بواجهة الوسائط المتوازنة وقائمة التطبيقات والمجلدات والبيانات السابقة.

ثبّت فوق النسخة الحالية دون حذفها. إذا رفض المُحدّث الداخلي فحص التوقيع افتح الملف من مدير ملفات أندرويد؛ السبب على الشاشة المتأثرة لم يُحسم.

لم يُختبر على شاشة سيارة فعلية في بيئة التطوير.
