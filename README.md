# درب 0.8.3

[تنزيل APK](apk/Darb-v0.8.3.apk) — أندرويد 8 فأحدث.

واجهة وسائط مركزية بأحجام تتكيف مع مساحة الصفحة وبروز ناعم للغلاف وزر التشغيل. تبقى الخيارات داخل الزر الجانبي الوحيد والتصاميم الثلاثة محفوظة.

إعدادات بمجموعات وصفوف مستوحاة من الآيفون وأيقونات ملوّنة، وصفحات فرعية للثيمات والتحديثات وحول التطبيق مع الرجوع للقائمة الأم. يحتفظ بمظهر التطبيقات الجديد من 0.8.2 وبالبيانات السابقة.

ثبّت فوق النسخة الحالية دون حذفها. إذا رفض المُحدّث الداخلي فحص التوقيع افتح الملف من مدير ملفات أندرويد؛ السبب على الشاشة المتأثرة لم يُحسم.

اجتاز البناء وLint وفحص التوقيع واختبارات منطق الواجهة والتراجع وتكيّف المقاسات؛ لم يُختبر بصريًا أو على شاشة فعلية في بيئة التطوير.
