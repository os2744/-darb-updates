# درب 0.10.0

[تنزيل APK](apk/Darb-v0.10.0.apk) — أندرويد 8 فأحدث.

خريطة حيّة في بطاقة الرئيسية وتبويبة كاملة، متابعة الموقع واتجاه الحركة، وضع المدينة والبر، حفظ الوجهات بالضغط المطوّل ونسخ الإحداثيات واستقبال روابط مشاركة متوافقة. زر واحد يجمع خيارات الخرائط.

Google Maps SDK مدمج برمجيًا لكنه **غير مفعّل لعدم توفر مفتاح مشروع Google Cloud**. تعمل OpenStreetMap الآن؛ تطبيقات الملاحة المتوافقة تفتح خارجيًا. لا ملاحة صوتية داخلية ولا تنزيل مناطق دون إنترنت.

المحدّث يعرض تقدم العملية، ويتيح إعادة الفحص وتثبيت الملف المنزّل. يعيد محاولة قراءة شهادة APK بالطريقة القديمة إذا غابت المعلومات الحديثة، ويميّز تعذّر القراءة عن اختلاف الشهادة. تبقى الملفات ذات التوقيع المختلف مرفوضة.

إذا منعك المحدّث القديم: ثبّت APK من مدير ملفات الشاشة فوق النسخة الحالية دون حذفها. لم يُختبر على شاشة المستخدم ولا يمكن ضمان حل عطل خاص بالشاشة دون تجربته. لا يتغيّر مفتاح التوقيع.
