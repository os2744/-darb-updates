# درب — تحديث الوسائط 0.8.0

[تنزيل APK](apk/Darb-v0.8.0.apk) — أندرويد 8 فأحدث، versionCode 9.

- 3 تصاميم مستقلة: غلاف مربع مركزي، أسطوانة تدور أثناء التشغيل، غلاف ممتد مع التعتيم.
- إعدادات الحركة والتعتيم ولون الأزرار، ووضع قيادة مبسّط.
- تبويبات الآن يعمل / تطبيقاتي / ملفاتي.
- اختيار مجلد الشاشة أو USB، بحث بالاسم وتصفية بالمجلد، حتى 1000 ملف.
- مشغّل صوتيات محلي بخدمة أمامية وجلسة وسائط وحفظ موضع الاستماع كل 5 ثوانٍ وعند الإيقاف.
- تقديم ورجوع 10/15/30 ثانية؛ التحكم بالتطبيقات الخارجية حسب دعمها.

ثبّت فوق النسخة الحالية دون حذفها. إذا تعطل المُحدّث القديم افتح APK من مدير الملفات. اجتاز البناء وLint واختبارات المنطق والواجهة، ولم يُختبر الصوت أو USB أو التثبيت على شاشة فعلية في بيئة التطوير.

لا يبدأ الصوت تلقائيًا بعد إعادة التشغيل؛ افتح الملف للاستئناف. قوائم الرحلات والتشغيل التلقائي للمقطع التالي مؤجلان.

المستودع لملفات التحديث العامة فقط.
