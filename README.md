# درب — تحديثات التطبيق

الإصدار الحالي **0.6.0** لأندرويد 8 أو أحدث.

[تحميل APK](https://raw.githubusercontent.com/os2744/-darb-updates/main/apk/Darb-v0.6.0.apk)

ثبّت هذا الإصدار فوق النسخة السابقة مرة واحدة. بعد ذلك: إعدادات درب ← تحديث التطبيق. يفحص آخر إصدار، ثم يعرض التنزيل والتثبيت عند توفر تحديث. لا يحتاج حساب GitHub على الشاشة.

## المصدر

[latest.json](https://raw.githubusercontent.com/os2744/-darb-updates/main/latest.json) يحتوي رقم الإصدار والحجم وبصمة SHA-256 ورابط APK. التنزيل من ملفات هذا المستودع مباشرة عبر HTTPS، وليس من صفحة تسجيل دخول أو رابط مؤقت.

يتحقق درب من حجم الملف وبصمته واسم الحزمة ورقم الإصدار والتوقيع قبل فتح مثبت أندرويد. يبدأ الفحص بالضغط على الزر فقط، ويظل تأكيد التثبيت بيد المستخدم.

## حالة الاختبار

بناء أندرويد وفحص Lint وتوقيع APK نجحت. لم تُختبر النسخة على شاشة فعلية؛ اختبرها كتطبيق عادي قبل تعيينها واجهة رئيسية. هذا إصدار تجريبي بتوقيع تطوير.

## نشر تحديث

ابنِ إصدارًا برقم أعلى وبالمفتاح نفسه، ثم ارفع APK داخل `apk/` وحدّث `latest.json` في commit واحد. حافظ على المسارات والأسماء القديمة. لا ترفع مفاتيح التوقيع أو حزمة المشروع الخاصة أو بيانات المستخدم إلى هذا المستودع.
