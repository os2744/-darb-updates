# درب 0.11.0

[تنزيل APK](apk/Darb-v0.11.0.apk) — أندرويد 8 فأحدث.

- «خرائطي»: برامج الخرائط المثبتة التي تستقبل إحداثيات geo، إرسال الوجهة وفتح التطبيق واختيار الافتراضي. إضافة يدوية للبرامج الأخرى مع توضيح «فتح التطبيق فقط». تفتح البرامج بواجهتها الخارجية.
- الخريطة الكاملة تملأ مساحة درب بلا إطار أو شريط جانبي أو تبويبات أو dock. أزرار عائمة للرجوع والخيارات، مع بقاء أشرطة أندرويد.
- زر Android Home يرجع إلى الرئيسية ويغلق الإعدادات ولوحة الوسائط عندما يكون درب واجهة Home الافتراضية.
- خمسة ثيمات للعداد: الكلاسيكي، الرقمي الكبير، الرياضي، المؤشر الكلاسيكي، والهادئ؛ الاختيار محفوظ ويظهر في البطاقة والعداد الكامل.

Google Maps داخل درب ما زال يحتاج مفتاح المشروع. فتح تطبيق Google Maps المثبّت خارجيًا لا يحتاج مفتاح SDK.

ثبّت فوق النسخة الحالية دون حذفها. إذا منعك المحدّث القديم، افتح APK من مدير ملفات الشاشة. لم يُختبر على شاشة سيارة فعلية هنا.
