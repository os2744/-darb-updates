# درب — تحديثات التطبيق

الإصدار الحالي **0.7.0** لأندرويد 8 أو أحدث.

[تحميل APK](https://raw.githubusercontent.com/os2744/-darb-updates/main/apk/Darb-v0.7.0.apk)

من درب 0.6 فأحدث: الإعدادات ← تحديث التطبيق ← تنزيل ← تثبيت. للإصدارات الأقدم، حمّل APK وثبّته فوق النسخة الحالية دون حذفها.

## جديد 0.7

- مجلدات مخصّصة للتطبيقات: إنشاء وتسمية ونقل وحذف المجلد دون حذف تطبيقاته.
- ترتيب ثابت بالسحب من المقبض وأزرار بديلة، إخفاء واسترجاع، أحجام الأيقونات وخيار الأسماء.
- حتى 6 مفضّلات صوتيات، مشغّل حالي واضح، والسابق/التالي أو رجوع 10 وتقديم 30 ثانية حسب دعم المشغّل.
- عرض مسار الرحلة مع فصل انقطاعات GPS؛ عرض مبسّط عند طول المسار، وGPX يحتفظ بالنقاط الكاملة.
- حفظ المخيم والموتر من GPS، مع اتجاه من الشمال ومسافة مباشرة وليست ملاحة لمسار صالح للقيادة.
- تصدير تقرير تشخيص بدون إحداثيات أو أسماء الأماكن أو التطبيقات؛ لا يُرسل تلقائيًا.

## التحقق

نجح البناء والتوقيع وAndroid Lint (صفر أخطاء)، و40 مجموعة اختبار للمنطق، واختبارات تفاعل DOM للمجلدات والوسائط والحفظ، وفحص المسار وفجواته. اختبارات DOM ليست اختبارًا بصريًا أو تجربة شاشة فعلية؛ GPS والوسائط والتثبيت على الجهاز ما زالت تحتاج تجربة. النسخة تجريبية بتوقيع تطوير.

## مصدر التحديث

[latest.json](https://raw.githubusercontent.com/os2744/-darb-updates/main/latest.json) يحتوي الإصدار والحجم وبصمة SHA-256 ورابط APK. يفحص التطبيق الحجم والبصمة واسم الحزمة والإصدار والتوقيع قبل فتح مثبت أندرويد. يبدأ الفحص عند الضغط فقط، ولا يحتاج تسجيل دخول على الشاشة.

## نشر تحديث لاحق

ابنِ الإصدار بمفتاح التوقيع نفسه وبرقم أعلى، وارفع APK داخل `apk/` مع تحديث `latest.json` في commit واحد. أبقِ الروابط والإصدارات القديمة. لا ترفع مفتاح التوقيع أو حزمة المشروع الخاصة أو بيانات المستخدم إلى هذا المستودع.
