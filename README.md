# درب 0.13.0

[تنزيل APK](apk/Darb-v0.13.0.apk) — أندرويد 8 فأحدث. ثبّت فوق النسخة الحالية دون حذفها.

أدوات درب من الزر أعلى الرئيسية أو الإعدادات:
- أوضاع المدينة والبر والسفر تحفظ الثيم والبطاقات والعداد والوسائط وخيارات الملاحة.
- تقسيم الرئيسية إلى خريطة درب ووسائط، مع فاصل قابل للسحب وتحكم تشغيل وتقديم.
- مكتبة 20 طلعة للأماكن والملاحظات ونسخ المسارات (حتى أول 1000 نقطة لكل طلعة).
- بطاقة وجهة بمسافة مباشرة وسهم من الشمال، وليست توجيهًا ملاحيًا.
- بحث في التطبيقات والأماكن والإعدادات، وقائمة اختصارات جانبية وزر سريع قابلان للتخصيص.
- نسخة احتياطية JSON حتى 2 ميجابايت مع مراجعة قبل الاستعادة.
- مشاركة المواقع برمز QR يُنشأ محليًا في أندرويد.
- راحة ليلية، مستويات حركة، معاينة الثيمات والبطاقات قبل الحفظ، وتراجع عن التخصيصات.
- حالة التخزين والإنترنت وGPS والصلاحيات، وفحص مبدئي لسياسة تضمين تطبيق الخرائط.

**Waze/OsmAnd داخل بطاقة درب غير مفعّل.** اختيار «افتراضي لإرسال الوجهات» يحدد التطبيق الخارجي فقط. فحص التوافق لا يفتح التطبيق داخل البطاقة ولا يختبر اللمس. Google Maps المدمجة تحتاج مفتاح المشروع.

النسخ الاحتياطي لا يشمل ملفات التطبيقات أو الموسيقى أو خرائط البرامج أو صلاحيات أندرويد. التعتيم الليلي يغيّر واجهة درب فقط.

تمت اختبارات البيانات وDOM والبناء؛ لم يُختبر على شاشة سيارة فعلية أو بصريًا هنا.
