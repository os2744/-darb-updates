# درب — تحديثات Android

الإصدار الحالي **0.17.0** (22).

- عدّاد داخل حلقة البوصلة، ملء الشاشة، حفظ تصاميم باسم، خيارات اتجاه الحساس والاستجابة، ومعاينة وسجل سرعة.
- تنبيهات رادارات ثابتة لقطر، بيانات محفوظة دون إنترنت وتصحيحات من لوحة المالك. 175 موقعًا مجتمعيًا أوليًا، 45 بحد معروف؛ التغطية غير شاملة.
- إصلاح تحميل ملفات القيادة داخل Android. التفعيل والإعدادات محفوظة عند التحديث فوق النسخة السابقة.

[تنزيل APK](apk/Darb-v0.17.0.apk) · [بيان التحديث](latest.json)

فعّل الرادارات من صفحة العدّاد، الزر الجانبي، «التنبيهات وبيانات قطر». تعمل أثناء ظهور درب ومع GPS حديث. الصوت العربي يعتمد على توفره بالجهاز وإلا نغمة. المواقع ليست كشفًا لإشارات الرادار وقد يكون هناك تنبيه من طريق موازٍ. اتبع اللوحات.
