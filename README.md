# درب — التحديثات

الإصدار 0.7.1 (8)، أندرويد 8 فأحدث.

[تنزيل APK](apk/Darb-v0.7.1.apk)

يحسن هذا الإصدار تشخيص فشل التحديث ويزيد مهلة الاتصال إلى 30 ثانية. يعرض مرحلة الفشل ورمزًا واضحًا ويحفظهما في تقرير التشخيص دون نصوص استثناءات أو عناوين خاصة. تبقى فحوص الحجم والبصمة والتوقيع مفعلة.

إذا منع الخطأ القديم التحديث، نزّل APK وافتحه من مدير ملفات أندرويد وثبته فوق النسخة الحالية دون حذفها. السبب على الجهاز المتأثر لم يُحسم بعد، ولم يُختبر الإصدار على شاشة فعلية.

هذا المستودع لملفات التحديث العامة فقط.
