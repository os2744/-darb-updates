# درب 0.12.0

[تنزيل APK](apk/Darb-v0.12.0.apk) — أندرويد 8 فأحدث.

- خيارات الخريطة في زر جانبي واحد: الرئيسية، خرائطي، موقعي، التكبير والتصغير، الأماكن وخيارات العرض.
- قائمة جانبية منزلقة وانتقالات قصيرة للصفحات والإعدادات والوسائط، مع احترام تقليل الحركة.
- تظل السرعة والموقع وحقوق الخريطة ظاهرة. اختيار برامج الخرائط المثبتة يفتحها خارجيًا.
- الاحتفاظ بثيمات العداد والإعدادات والأماكن والمفضلات السابقة.

Google Maps المدمجة تحتاج مفتاح المشروع وخدمات Google Play. فتح تطبيق الخرائط المثبت خارجيًا لا يحتاج مفتاح SDK.

ثبّت فوق النسخة الحالية دون حذفها. إذا منعك المحدّث القديم، افتح APK من مدير ملفات الشاشة. لم يُختبر على شاشة سيارة فعلية هنا.
