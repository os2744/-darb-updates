# درب 0.14.0

[تنزيل APK](apk/Darb-v0.14.0.apk) — أندرويد 8 فأحدث، يثبت فوق النسخة الحالية.

من أدوات درب ← الجوال والشريط العائم وبدء التشغيل:
- اقتران محلي مؤقت لإرسال الإحداثيات وروابط الخرائط من متصفح الجوال للشاشة عبر QR. يبقى درب مفتوحًا والجهازان على الشبكة نفسها. خمس دقائق، ويتوقف عند مغادرة درب. HTTP محلي غير مشفّر؛ بعض الهوتسبوتات تعزل الأجهزة فتمنع الربط.
- شريط عائم اختياري قابل للسحب والتصغير، للرئيسية والوسائط وحفظ المكان والتحكم في جلسة الوسائط. يلزم إذن الظهور فوق التطبيقات. الإيقاف من الشريط أو الإشعار أو الإعدادات.
- بدء درب على الرئيسية أو آخر صفحة، وحفظ آخر مشغّل وسائط مختار، وتجديد طلب الموقع والوسائط عند العودة بدون تشغيل صوت تلقائي.

الشريط لا يضمّن تطبيق الخرائط. تشغيل درب عند إشعال السيارة يعتمد على اللانشر الافتراضي وسياسة الشاشة. حفظ المكان من الشريط يفتح درب للمراجعة.

اختُبر الخادم المحلي والتحقق من الاقتران والواجهات والبناء والتوقيع؛ لم يُختبر الشريط أو اتصال الهوتسبوت فعليًا على شاشة المستخدم.
